# 🏫 Online Junior Secondary School (Class 4–8)

An interactive and fully functional **Online Junior Secondary School System** developed for **Class 4 to 8** students.  
This project is built using **Django**, **HTML**, **CSS**, and **MySQL**, providing a complete digital platform for teaching, learning, and school management.

---

## 🎯 Project Overview

The **Online Junior Secondary School** system aims to digitalize traditional education by offering online access to academic resources, assignments, results, and communication between students, teachers, and administrators.

It bridges the gap between physical classrooms and virtual education, ensuring that students from **Class 4 to 8** can learn and interact effectively through a user-friendly web interface.

---

## 🚀 Key Features

### 👨‍💼 Admin Panel
- Manage teachers, students, and subjects  
- Create and update class schedules  
- Monitor attendance and results  
- Handle notices, exams, and reports  
- Manage database and user roles  

### 👩‍🏫 Teacher Panel
- Upload lesson materials and assignments  
- Evaluate student submissions and publish grades  
- Maintain attendance records  
- Communicate with students  

### 👩‍🎓 Student Panel
- Register and log in securely  
- Access class schedules and subjects  
- Submit assignments and view marks  
- Check attendance and exam results  
- Receive notices and study materials
